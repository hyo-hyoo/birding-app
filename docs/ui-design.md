# 观鸟 Web App｜UI 设计

> 文档状态：低保真设计与视觉方向实验整理中
> 当前低保真原型：`prototype/low-fidelity.html`
> 当前视觉实验原型：`prototype/experiments/visual-direction-comparison.html`
> 原型用于核对页面、结构、导航、组件、状态和已出现的交互，不作为需求确认依据。
> 产品能力以 `requirements.md` 为准，MVP 边界以 `mvp-scope.md` 为准。

## 1. 状态说明

- **已确认**：用户已经接受，可作为当前 UI 设计依据。
- **MVP 暂定**：当前用于低保真或 MVP 方案，但仍可能调整。
- **未确认**：需要用户继续选择或澄清。
- **Observed-only**：只在 HTML 原型中出现，没有足够证据证明已获确认。
- **视觉实验／暂定**：用于验证设计方向，可以继续调整，不是正式品牌、组件或高保真规范。
- **已延后或不属于 MVP**：不进入当前版本。

## 2. 当前用户流程

### 2.1 账户入口

**已确认**

- 已有账户：登录 → 个人观察历史。
- 没有账户：登录 → 注册 → 完成注册。
- 登录页和注册页提供显示语言入口。

**MVP 暂定**

- 注册成功后直接进入个人观察历史。

### 2.2 新建观察

**已确认**

个人观察历史 → 轮廓选择 → 观察记录编辑 → 查看抽象图和摘要 → 修正 → 保存 → 观察记录详情。

编辑时可以自由选择头部、胸腹、翅膀和尾部，所有部位均可跳过。

### 2.3 回看与继续编辑

**已确认**

个人观察历史 → 观察记录详情 → 编辑 → 修改结构化特征 → 保存 → 返回详情。

### 2.4 鸟种确认

**已确认**

- 用户可以在日后补充鸟种确认信息。
- 记录区分待确认和已确认；已确认记录显示鸟名。

**MVP 暂定**

- 在观察记录详情页内提供确认入口。
- 暂时通过填写鸟名将记录改为已确认。

### 2.5 设置与语言

**已确认**

- 登录后的设置页集中提供显示语言切换和退出登录。
- 登录页和注册页保留登录前语言入口。
- 登录后不在每个业务页面重复显示语言入口。

## 3. 页面清单与页面结构

当前低保真范围包含 7 个页面。

| 页面 | 状态 | 主要目的 | 主要入口与去向 |
| --- | --- | --- | --- |
| 登录 | 已确认 | 登录并进入个人观察历史 | 注册入口；成功后进入观察历史 |
| 注册 | 已确认 | 创建可保存个人观察的账户 | 返回登录；成功去向暂定为观察历史 |
| 个人观察历史 | 已确认 | 查看记录、寻找待确认记录、新建或打开记录 | 新建 → 轮廓选择；记录 → 详情；设置 → 设置页 |
| 轮廓选择 | 已确认 | 选择最接近记忆的整体轮廓 | 继续 → 编辑；返回 → 观察历史 |
| 观察记录编辑 | 已确认 | 记录特征并查看抽象图和摘要 | 保存 → 详情；修改轮廓 → 轮廓选择；取消 → 历史 |
| 观察记录详情 | 已确认 | 查看、回忆、继续编辑和补充鸟种确认 | 编辑 → 编辑页；返回 → 历史；确认操作暂定内嵌 |
| 设置 | 已确认进入当前低保真范围 | 切换显示语言或退出登录 | 历史、新建观察；退出 → 登录 |

### 3.1 登录页面

**已确认组件**：产品标识、登录凭据输入区、登录按钮、注册入口、语言入口。

**MVP 暂定**：邮箱和密码；登录失败时保留错误提示状态。

**Observed-only**：产品标识形式、输入框样式、错误提示位置和文案。

### 3.2 注册页面

**已确认组件**：注册信息输入区、注册按钮、登录入口、语言入口。

**MVP 暂定**：邮箱、密码、确认密码；注册成功后进入观察历史。

**已确认不需要**：头像、昵称、个人简介和其他个人资料字段。

### 3.3 个人观察历史

**已确认组件**：新建观察入口；记录卡片；抽象图缩略图；确认状态；已确认鸟名。

**MVP 暂定**：纵向卡片列表；没有抽象图时使用轮廓或占位图；显示 App 底部导航。

**Observed-only**：空状态、示例卡片数量、具体占位文案，以及时间或地点占位。

### 3.4 轮廓选择

**已确认组件**：说明文字、轮廓选项、选中状态、继续按钮和返回入口。

**MVP 暂定**：单层网格、4～6 个占位轮廓、工作名称；不显示 App 底部导航。

**未确认**：最终数量与分类、单层或分层、“没有合适轮廓”、飞行轮廓。

**Observed-only**：轮廓 A～F、具体选中项、飞行轮廓占位。

### 3.5 观察记录编辑

**已确认组件**：当前轮廓、标准侧面鸟体图、四个可选部位、主色、可选补充色、花纹或特征、补充文字、三档确定程度、抽象图预览、文字摘要、保存和取消。

**已确认保存条件**：用户已经选择一个大致整体轮廓，并且头部、胸腹、翅膀、尾部中至少一个身体部位记录了颜色、花纹或特征标签、自由文字描述中的任意一种有效特征后，才能保存。其他身体部位仍可跳过；第一版不引入草稿状态、草稿页面或自动保存。

**MVP 暂定**：纵向滚动；部位编辑区在页面下部展开或以底部面板出现；完成一次编辑后更新生成结果；不显示 App 底部导航；主要通过结构化输入修正。

**未确认**：展开区或底部弹层、生成结果位置、保存条件采用禁用按钮、即时提示还是提交后错误提示、一般备注、抽象图直接修改范围。

**Observed-only**：具体颜色数量、标签示例、示例值和部位视觉标记。

### 3.6 观察记录详情

**已确认组件**：抽象图、文字摘要、确认状态、已确认鸟名、编辑入口和返回入口。

**MVP 暂定**：内嵌鸟种确认区、鸟名自由文字、确定程度展示、App 底部导航。

**未确认**：撤销确认、修改鸟名、候选状态、原始特征变化对确认状态的影响、确定程度展开方式。

**Observed-only**：鸟名输入与确认按钮的具体形式、摘要排版和按钮排列。

### 3.7 设置页面

**已确认组件**：设置标题、App 显示语言、退出登录和 App 底部导航。

**MVP 暂定**：简体中文和日本語；暂时不加入其他复杂设置。

**未确认**：跟随系统、语言偏好保存范围、切换后的反馈或刷新、其他账户与显示选项。

**Observed-only**：设置行、说明框、退出按钮的具体布局与样式。

## 4. App 底部导航

**已确认**

| 导航项目 | 对应页面 |
| --- | --- |
| 观察历史 | 个人观察历史 |
| 新建观察 | 轮廓选择 |
| 设置 | 设置页面 |

**MVP 暂定显示规则**

| 页面 | 是否显示 |
| --- | --- |
| 登录、注册 | 不显示 |
| 个人观察历史 | 显示 |
| 轮廓选择、观察记录编辑 | 不显示 |
| 观察记录详情 | 显示 |
| 设置 | 显示 |

**未确认**

- 详情页是否最终保留底部导航；
- 新建观察入口是否突出显示；
- 是否使用图标及最终文案；
- 未保存编辑内容时触发返回或其他导航的处理。

原型外围用于切换七张线框稿的导航只服务于原型浏览，不属于 App UI。

## 5. 显示语言交互

**已确认**

- 登录页和注册页顶部使用一个显示当前语言的按钮。
- 点击按钮后展开单选下拉菜单。
- 不采用两个并列语言按钮作为正式交互。
- 登录后统一在设置页切换语言。

**MVP 暂定**

- 语言选项为简体中文和日本語。

**未确认**

- 下拉方向、图标及语言名称表现；
- 设置页是否复用同一个下拉组件；
- 语言偏好保存范围；
- 切换后是否立即刷新当前页面。

## 6. 原型核对结果

`prototype/low-fidelity.html` 当前实际包含：

- `p1`～`p7` 七个页面；
- 原型外围的七页面演示切换；
- 观察历史、记录详情和设置页中的 App 底部导航；
- 底部导航前往观察历史、轮廓选择和设置页的 JavaScript 切换；
- 登录页和注册页的语言选项切换；
- 已确认和暂定状态标签。

大部分页面内按钮目前是静态线框元素，不代表相关提交、保存、返回或确认业务已经实现。

### 原型表现与正式方案的差异

HTML 在登录页和注册页使用两个并列语言选项，是为了在低保真阶段直观表达“支持语言切换”，不代表正式交互方案。最新确认的正式方案仍是单一语言按钮加下拉菜单；本次不修改 HTML。

## 7. 当前视觉方向实验

### 7.1 实验范围与状态

**已确认的工作方式**

- UI 设计任务先使用 `$frontend-design` 建立视觉方向，再使用 `$mobile-app-ui-design` 检查移动端体验；
- 视觉探索采用最小原则：先用一个代表性的观察记录编辑页验证方向，不同时为全部七个页面制作多个版本；
- 当前只继续探索 B 方向，暂称“B′ 柔雾标本册”；
- 当前工作属于原型和方向验证，不代表进入 Rails 业务代码实现。

**视觉实验／暂定**

- 当前版式尝试使用连续观察记录纸、羽色索引、柔和分区和底部固定保存操作；
- 这些元素用于判断 B′ 的柔和程度、整体设计感和产品辨识度，尚未成为正式视觉语言或组件规范。

### 7.3 原型观察与边界

`prototype/experiments/visual-direction-comparison.html` 当前已经收敛为一个 B′ 观察记录编辑页实验，不再构成 A、B、C 三个方向的有效比较。

原型中已经出现连续记录纸布局、抽象枝头鸟轮廓、羽色索引、胸腹编辑区、文字印象摘要和固定保存按钮。页面的具体样式、示例颜色、示例花纹、示例值及鸟体图均为 **Observed-only**，不得据此新增正式需求或 MVP 决定。

实验页没有引入外部资源、前端框架或新的业务依赖。外部 Skill 中提到的 React、Tailwind、React Native、Flutter 和 SwiftUI 不属于项目默认技术要求；Web App 仍以 Rails Views、HTML、CSS、JavaScript、Turbo 和 Stimulus 为默认方向，SwiftUI 只能作为视觉或交互参考。

### 7.4 已延后或否决的探索方式

- 只改变少量颜色、圆角和局部装饰的 A／B／C 对比已被否决，不作为有效视觉方向比较结果；
- 暂不同时制作 A、B、C 三套完整页面；
- 暂不把 B′ 扩展到全部界面。

### 7.5 待确认

- B′ 页面是否达到期望的柔和程度和整体设计感；
- B′ 是否最终成为项目正式视觉方向；
- 当前实验色值全部保留还是继续调整；
- 羽色索引、连续记录纸和当前鸟体表现是否适合作为产品的标志性视觉语言；
- 视觉方向确认后，是先扩展少量关键页面，还是直接制作完整高保真流程；
- 最终字体、间距、圆角、阴影、插画和动效规范。

## 8. 当前不单独建立页面

**MVP 暂定**

- 鸟种确认合并到观察记录详情页；
- 登录前语言选择放在登录和注册页，登录后放在设置页；
- 抽象图和摘要放在编辑页及详情页；
- 编辑已保存记录复用观察记录编辑页。

## 9. 已延后或不属于 MVP

- 营销首页、公开主页、社交与投稿页面；
- 鸟类文化、候选鸟种推荐、地图和分布页面；
- 管理员内容审核页面；
- 高保真视觉规范、正式品牌配色、插画和动效规格；
- 自由绘图、复杂图形编辑和高自由度变形；
- 复杂设置中心、主题切换、通知、数据导入导出；
- 原生 App 专属导航和正式 LINE MINI App 适配。

- 鸟名输入、撤销确认和候选状态；
