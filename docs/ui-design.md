## 1. 状态说明

- **已确认**：用户已经接受，可作为当前 UI 设计依据。
- **MVP 暂定**：当前用于低保真或 MVP 方案，但仍可能调整。
- **未确认**：需要用户继续选择或澄清。
- **Observed-only**：只在未获确认的原型或示例层出现，没有足够证据证明已获确认；不包括已经明确纳入正式高保真实现基线的视觉层内容。
- **视觉实验／暂定**：用于验证设计方向，可以继续调整，不是正式品牌、组件或高保真规范。
- **正式实现基线**：已确认的整体视觉方向和页面实现参考；允许根据浏览器效果进行必要适配，但不得擅自改变整体方向。
- **已延后或不属于 MVP**：不进入当前版本。

## 2. 当前用户流程

### 2.1 账户入口

**已确认**

- 已有账户：登录 → 个人观察历史。
- 没有账户：登录 → 注册 → 查收 15 分钟验证链接；必要时从注册结果页直接重发，或重新输入邮箱请求发送 → 打开验证链接 → 查看脱敏邮箱并确认 → 服务器完成验证 → 返回登录 → 用户手动登录 → 个人观察历史。
- 忘记密码：登录 → 申请重置 → 打开邮件中的 30 分钟有效链接 → 设置新密码 → 返回登录 → 用户手动登录。
- 登录页和注册页提供显示语言入口。
- 注册、验证邮件已发送、重新输入邮箱发送和登录采用相对独立的页面，并具有清晰的前后入口。
- 打开邮箱验证链接时统一进入服务器验证入口；服务器首次检查有效链接后先显示带脱敏邮箱的确认页，用户提交确认时再次检查并完成验证。链接过期、无效、已使用、已被替换和账户已经验证等结果均由服务器判断，不能由查询参数或浏览器状态指定。
- 重复注册不会创建第二个账户或自动重发邮件，只显示登录和重新验证入口，不泄露账户验证状态。注册已创建账户但邮件暂未发出时，结果页说明情况并提供统一重发入口。
- 邮箱不存在或密码错误使用同一登录错误提示；凭证正确但账户未验证时，页面可以提示完成验证并提供重发入口，但不会进入登录状态。
- 主动登录成功后进入观察历史；从受保护页面跳转到登录时可以返回有效的站内原页面，外部或无效返回地址统一进入观察历史。

### 2.2 新建观察

**已确认**

个人观察历史 → 第一层视觉大组 → 第二层具体轮廓或“没有合适的轮廓” → 观察记录编辑 → 查看抽象图和摘要 → 修正 → 保存 → 观察记录详情。

编辑时可以自由选择头部、胸腹、翅膀和尾部，所有部位均可跳过。

编辑页默认显示头部面板，但只有用户填写有效内容后才产生头部数据。有未保存修改时离开编辑流程，需要选择继续编辑或放弃修改后离开。

预览使用当前表单内容更新抽象图和摘要，不代表数据已经保存；首次保存成功后进入详情页。服务器校验失败时停留在编辑页、保留输入并在对应位置显示错误，不展示部分保存成功的状态。

### 2.3 回看与继续编辑

**已确认**

个人观察历史 → 观察记录详情 → 编辑 → 修改结构化特征 → 保存 → 返回详情。

### 2.4 鸟种确认

**已确认**

- 鸟种识别统一在保存后的详情页进行，不进入首次现场记录流程。
- 状态由数据自动计算为待确认、候选中或已确认，用户不直接选择状态。
- 用户最多维护三个自由输入的候选鸟名，并可以增加、删除或替换。
- 最终确认时可以选择一个候选，也可以输入另一个最终鸟名。
- 用户可以修改最终鸟名或撤销确认；编辑观察特征不会自动取消已确认状态。
- 仅切换候选不产生未保存状态；添加候选和确认最终鸟名由对应操作按钮直接生效，不再经过第二个统一保存按钮。
- 删除普通候选和修改最终鸟名属于可能丢失原数据的暂存操作，需要明确保存和未保存离开保护。
- 存在这两类尚未保存的暂存修改时，立即生效的添加、确认或撤销操作先要求用户保存或放弃暂存修改，避免两个保存范围互相覆盖。
- 候选或其他最终鸟名输入框存在非空未提交文字时，离开页面需要保护。
- 最终鸟名仍在候选中时撤销立即生效；不在候选中时询问是否保留为候选，候选已满且决定保留时由用户明确选择替换项，不静默删除名称。

### 2.5 设置与语言

**已确认**

- 登录后的设置页集中提供显示语言切换和退出登录。
- 登录页和注册页保留登录前语言入口。
- 登录后不在每个业务页面重复显示语言入口。
- 设置页还包含当前邮箱只读展示和修改密码。

## 3. 页面清单与页面结构

当前低保真原型包含 7 个核心页面，以及用于集中演示账户相关内部状态的“08 账户辅助流程”。邮箱验证、忘记密码、密码重置和修改密码已经进入低保真原型；原型中的集中演示方式不改变注册、验证邮件已发送、重新输入邮箱发送和登录采用相对独立页面的决定。

| 页面 | 状态 | 主要目的 | 主要入口与去向 |
| --- | --- | --- | --- |
| 登录 | 已确认 | 使用邮箱和密码登录 | 注册、忘记密码、语言入口；成功后进入观察历史 |
| 注册 | 已确认 | 创建可保存个人观察的账户 | 返回登录；提交后等待邮箱验证，确认成功后返回登录 |
| 个人观察历史 | 已确认 | 查看记录、寻找待确认记录、新建或打开记录 | 新建 → 轮廓选择；记录 → 详情；设置 → 设置页 |
| 轮廓选择 | 已确认 | 通过两层纯视觉流程选择最接近的轮廓或兜底项 | 继续 → 编辑；返回 → 观察历史 |
| 观察记录编辑 | 已确认 | 记录视觉特征与补充信息并查看生成结果 | 保存 → 详情；修改轮廓 → 轮廓选择；取消或离开时处理未保存修改 |
| 观察记录详情 | 已确认 | 查看记录、继续编辑和管理鸟种识别 | 编辑 → 编辑页；候选与确认操作在本页；返回 → 历史 |
| 设置 | 已确认进入当前低保真范围 | 查看邮箱、修改密码、切换语言或退出登录 | 历史、新建观察；退出 → 登录 |
| 账户辅助流程状态集合 | 已确认进入低保真范围 | 集中演示注册验证、忘记密码和修改密码的内部状态 | 从注册、登录或设置进入所属流程；不作为一个正式一级产品页面 |

### 3.1 登录页面

**已确认组件**：产品标识、邮箱、密码、登录按钮、注册入口、忘记密码入口和语言入口。

**已确认视觉资源**：第三版 Logo 已确认为正式 App Logo，资源见 `prototype/assets/app-logo-preview.png`；高保真登录页当前使用该 Logo。

**MVP 暂定**：登录失败时保留错误提示状态。

**Observed-only／实现细节**：输入框样式、错误提示位置和文案，以及登录页当前约 72px 的 Logo 尺寸、柔和投影和具体间距。

### 3.2 注册页面

**已确认组件**：邮箱、密码、确认密码、注册按钮、登录入口和语言入口。

**已确认流程**：注册后显示查收验证邮件的反馈；验证链接有效期为 15 分钟；注册结果页可以直接重发，用户也可以重新输入邮箱请求发送；两个入口使用一致且不泄露账户是否存在的结果反馈；邮箱确认成功后返回登录页，不自动登录。

**已确认错误与字段保留**：注册输入校验失败时保留邮箱，清空密码和确认密码；用户能够直接修正的输入问题显示在对应字段附近。邮件服务内部故障使用不暴露技术细节的页面提示，具体错误只写入服务器日志。

**已确认不需要**：头像、昵称、个人简介、用户名登录、第三方 OAuth 和其他个人资料字段。

### 3.3 个人观察历史

**已确认组件**：新建观察入口；记录卡片；抽象图缩略图；待确认、候选中或已确认状态；已确认记录的最终鸟名。

**MVP 暂定**：纵向卡片列表；没有抽象图时使用轮廓或占位图；显示 App 底部导航。

**已确认展示规则**：候选中记录只显示“候选中”，不显示候选鸟名；已确认记录显示状态和最终鸟名；历史卡片不显示行动位置和行为。

**Observed-only**：空状态、示例卡片数量、具体占位文案，以及原型中的时间或地点占位。

### 3.4 轮廓选择

**已确认结构**：两层纯视觉选择；第一层约 4 个视觉大组，以剪影为主、短文字为辅；第二层约 12～14 个具体轮廓，目标约 13 个但不写死。

**已确认组件**：说明文字、第一层大组、第二层具体轮廓、“没有合适的轮廓”、选中状态、继续按钮和返回入口。

**已确认边界**：不显示 App 底部导航；兜底项使用中性通用鸟体；不提供自由绘图、自由变形或专门的飞行鸟轮廓。

**待专项验证**：最终大组与轮廓名单、名称、排序及福冈常见鸟样本覆盖。

**Observed-only**：轮廓 A～F、具体选中项、飞行轮廓占位。

### 3.5 观察记录编辑

**已确认结构**：标准鸟体图与部位切换 → 固定的当前部位编辑面板 → 生成结果（抽象鸟图和摘要）→ 可选补充信息 → 保存或取消。

**已确认组件**：当前轮廓、标准侧面鸟体图、四个可选部位、主色、可选补充色、最多一个预设花纹或特征、部位自由文字、三档确定程度、抽象图预览、文字摘要、最多两个行动位置、行为自由文字、保存和取消。

**已确认选项规则**：全部部位共用约 10～12 个基础颜色家族；每个部位最多一个补充色和一个预设花纹或特征标签；具体颜色、显示色值和标签名单必须在实现前专项验证。部位自由文字完整进入摘要，但不改变抽象图。

**已确认默认状态**：默认显示头部编辑面板，但不自动产生头部数据。

**已确认保存条件**：用户已经选择普通轮廓或“没有合适的轮廓”，并且至少一个身体部位记录了颜色、花纹或特征标签、自由文字描述中的任意一种有效特征后，才能保存。行动位置和行为不影响保存条件；第一版不引入草稿或自动保存。

**已确认更新与修正**：完成一个部位编辑或切换部位后统一更新抽象图和摘要；只能修改结构化输入，不能直接拖拽、绘制或改变图形。

**已确认离开保护**：已有未保存修改时，离开编辑流程必须二次确认，提供继续编辑和放弃修改后离开。

**未确认 UI 细节**：保存条件采用禁用按钮、即时提示还是提交后错误提示；未保存确认框的具体文案与视觉表现。

**Observed-only**：具体颜色数量、标签示例、示例值和部位视觉标记。

### 3.6 观察记录详情

**已确认组件**：抽象图、文字摘要、每个部位的确定程度、正式记录时间、行动位置、行为、识别状态、候选鸟名管理、最终鸟名、修改或撤销确认、编辑入口、返回入口和 App 底部导航。

**已确认状态交互**：状态根据候选与最终鸟名自动变化；最多三个候选；可以从候选确认或输入其他最终鸟名；撤销确认后按剩余候选自动回退状态；修改观察特征不取消已确认状态。

**已确认保存与防误操作规则**：仅切换候选不产生未保存状态；添加候选的“添加”按钮和设置最终鸟名的确认按钮直接使操作生效，不显示第二个保存按钮；删除普通候选和修改最终鸟名需要暂存、明确保存和未保存离开保护。

**已确认页面结构**：修改最终鸟名时只显示一个预填输入框，不同时展示修改前后的名称；已确认状态保留候选鸟名，候选区域默认折叠；正文底部不重复设置返回历史和编辑观察入口。

**已确认撤销与离开保护规则**：最终鸟名仍在候选中时撤销立即生效；不在候选中时询问是否保留为候选；决定保留且候选已满三个时，由用户明确选择替换哪个候选。候选或其他最终鸟名输入框存在非空未提交文字时，离开页面需要保护。

**静态前端已验收、但仍属当前实现细节**：阶段 5 已通过整体用户验收；当前候选折叠入口文案、弹窗微文案、按钮层级和满额替换候选的视觉表现仍为 **Observed-only／暂定实现**，不自动成为最终 UI 规范。

**未确认 UI 细节**：候选折叠入口的最终文案、视觉层级和展开后的管理控件；各部位确定程度的具体排版。

**已过期实现记录**：阶段 5 初版曾把添加候选、确认最终鸟名和撤销确认统一放入保存栏，并在已确认页面完整展开候选区域；这些表现已被后续决定取代，不得作为待验收依据。

### 3.7 设置页面

**已确认组件**：设置标题、当前邮箱只读展示、修改密码、App 显示语言、退出登录和 App 底部导航。

**已确认边界**：不支持修改邮箱，不提供“跟随系统”，暂时不加入其他复杂设置。

**Observed-only**：设置行、说明框、退出按钮的具体布局与样式。

### 3.8 账户辅助界面与状态

**已确认需要支持**：注册后查收验证邮件、邮箱确认结果、忘记密码申请、重置密码表单、重置成功反馈，以及设置页中的修改密码。

**已确认字段**：修改密码需要当前密码、新密码和确认新密码；重置密码通过邮件限时链接进入，不使用邮件验证码。

**已确认入口层级**：用户可主动选择的功能入口只有忘记密码和修改密码。设置新密码与重置成功属于忘记密码流程内部状态；验证邮件与验证结果属于注册流程内部状态；密码错误等异常反馈也保留在所属流程内部，不增加一级功能入口。

**已确认链接与重发规则**：邮箱验证链接在 15 分钟内有效；密码重置链接在 30 分钟内有效，只有最新链接有效且成功使用后不可重复使用。验证邮件可以从注册结果页直接重发，也可以通过重新输入邮箱请求发送；两个入口的结果反馈不得泄露账户是否存在。

**MVP 暂定呈现**：忘记密码、设置新密码、重置成功和修改密码暂继续使用独立全屏状态；不增加新的一级功能入口。

**当前静态错误预览**：登录凭证错误和注册密码不一致使用查询参数触发代表性错误画面；具体文案、红色强调和查询参数方式属于当前前端暂定实现。真实服务器反馈、提交后焦点位置和字段值保留方式等待后端接入后验证。

**已确认页面与状态组织**：注册、验证邮件已发送、重新输入邮箱发送和登录分别使用相对独立页面。邮箱验证链接使用统一服务器入口：有效链接先显示带脱敏邮箱的确认页，用户确认后再完成验证；服务器根据真实令牌显示成功、过期、无效、已使用、已被替换或已经验证等结果。邮件扫描器只打开链接时不会直接验证账户。

**已确认反馈分工**：用户可以直接修正的输入错误使用字段错误；邮箱不存在与密码错误使用同一页面级通用提示，凭证正确但账户未验证时可以明确提示验证并提供重发入口；验证邮件已发送、验证成功、链接过期或无效等流程结果使用结果页面或结果卡片；请求过于频繁和邮件服务故障使用明确但不泄露账户状态或技术细节的通用提示。注册已创建账户但邮件暂未发出时，页面保留账户已创建的事实并提供重试入口。

**已确认密码完成状态**：忘记密码重置成功后结束全部现存会话并返回登录页；登录后修改密码成功时保留当前会话、结束其他会话。具体成功提示文案仍可在真实后端接入时验证。

**已确认安全边界**：真实验证结果、登录结果和邮件发送结果不得由查询参数或浏览器自行指定。当前由查询参数触发的账户错误与结果画面只可作为静态预览方式，不能作为正式数据流。

**MVP 暂定呈现**：真实后端页面优先复用现有静态前端的布局、Partial、字段错误组件、页面提示和结果卡片，不另行建立视觉体系。静态预览路由是否长期保留为本地开发参考，由开发 Agent 在不影响正式路由的前提下判断。

**未确认 UI 细节**：忘记密码、设置新密码、重置成功和修改密码的最终路由或状态拆分；账户异常反馈的最终文案、提交后的焦点位置和字段值保留方式。
