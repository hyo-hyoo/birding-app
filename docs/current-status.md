# 观鸟 Web App｜当前状态

> 进入项目的新 ChatGPT 对话或 Codex 线程时，请先阅读本文件，再阅读 `project-overview.md`、`requirements.md` 和 `mvp-scope.md`。

## 当前阶段

产品需求、MVP 范围、主要技术路线和 B′ 完整 MVP 高保真页面实现基线已经确认，正式前端开发可以开始。

当前工作区已出现尚未跟踪的 Rails 项目骨架，但尚未提交、运行或验证，也没有已确认完成的业务功能。高保真页面齐备表示 UI 实现参考已经就绪，不表示 Rails 页面或业务功能已经完成。

## 已确认

- 产品是面向普通用户、移动端优先的观鸟 Web App；
- 核心用户主要使用望远镜，没有照片或不希望依赖照片识别；
- 核心问题是保存会迅速消失的颜色、花纹和局部视觉印象；
- 第一阶段优先覆盖福冈日常、静态或低速活动中的鸟；
- 第一版以结构化输入为主；
- 轮廓采用两层纯视觉选择，第一层约 4 个大组、第二层约 12～14 个具体轮廓，并提供“没有合适的轮廓”兜底项；
- 第一版可记录部位为头部、胸腹、翅膀和尾部；
- 每个部位均为可选；
- 编辑页默认显示头部面板，但未填写有效内容时不产生头部数据；
- 每个部位支持一个主颜色和一个可选补充色；
- 每个部位最多选择一个预设花纹或特征标签，其他细节使用自由文字补充；自由文字进入摘要但不影响抽象图；
- 确定程度采用三档：确定、大概如此、非常模糊；
- 用户完成一个部位编辑或切换部位后，系统统一更新抽象鸟类印象图和文字摘要；抽象图只通过结构化输入修正；
- 新建观察记录只有在选择普通轮廓或兜底轮廓，并且至少一个身体部位记录有效视觉特征后才能保存；
- 第一版不引入草稿状态、草稿页面或自动保存；
- 有未保存修改时离开编辑流程必须二次确认继续编辑或放弃修改；
- 可选补充最多两个行动位置标签和行为自由文字；不设置手动观察时间、独立地点、环境或普通备注字段；
- 鸟种识别状态为待确认、候选中和已确认，根据候选与最终鸟名自动计算；最多保存三个自由输入的候选鸟名；
- 第一版采用邮箱和密码账户，注册后必须验证邮箱再手动登录，并支持邮件链接重置密码和登录后修改密码；
- 观察历史优先显示抽象图缩略图和识别状态；候选中不显示候选名，已确认显示最终鸟名；
- 当前低保真原型包含登录、注册、观察历史、轮廓选择、记录编辑、记录详情和设置七个核心页面，以及“08 账户辅助流程”状态集合；该辅助流程顶部只保留忘记密码和修改密码，邮箱验证、设置新密码与结果反馈归入各自流程内部；
- 底部导航包含观察历史、新建观察和设置，只在观察历史、观察详情和设置页显示；
- MVP 显示语言为简体中文和日本語；主动选择只保存在当前浏览器并立即生效；
- 设置页面包含当前邮箱、修改密码、显示语言和退出登录；
- Ruby on Rails 仍是主要后端学习与开发方向。

## 已确认技术方向

- 使用 Windows 原生开发环境、Ruby 4.0.6、Rails 8.1.x 和 MySQL 8.4 LTS；
- 保留现有 MySQL 5.7 服务及数据；MySQL 8.4 使用独立服务、数据目录和端口，当前规划服务名为 `MySQL84`、端口为 `3307`；
- 采用 Rails 模块化单体、Rails Views、Turbo、Stimulus 和少量普通 JavaScript，MVP 不采用 Vue、独立 SPA、独立前端仓库或纯 API 后端；
- 抽象图使用服务器生成的 inline SVG，并通过 Turbo Frame 与 Stimulus 渐进预览；只持久化结构化观察数据；
- 采用 Rails 8 第一方认证、`has_secure_password`、数据库 Session、Rails Cookie 和当前用户作用域授权；
- 邮箱验证和密码重置链接均在 15 分钟内有效；验证邮件支持注册结果页直接重发和重新输入邮箱请求发送；
- 使用 Rails I18n；不支持的浏览器语言默认回退到日文，语言偏好只保存在当前浏览器；
- 使用 Minitest 测试体系和本地运行、部署准备、公开部署三阶段交付；
- 第一个纵向切片确认为“可登录的空观察历史”。

## 当前 UI 实现基线

- 项目级 `$project-ui-designer` 负责 UI/UX、页面流程、原型制作与验证，并在产生实质性 UI 决定时输出一次性交接单；它不直接修改正式项目文档；
- UI 视觉任务由 `$project-ui-designer` 先使用 `$frontend-design` 建立视觉方向，再使用 `$mobile-app-ui-design` 检查移动端体验；
- B′“柔雾标本册”已经确认为正式页面视觉方向；
- `prototype/experiments/high-fidelity-baseline.html` 是整个 MVP 的正式高保真实现基线，覆盖登录、注册、账户辅助流程、空与非空观察历史、轮廓选择、观察编辑、观察详情、设置、修改密码、设计系统和 Rails 前端组件参考；
- 第一个纵向切片需要的注册、邮箱验证、手动登录和空观察历史已经具有高保真页面参考；
- `prototype/assets/app-logo-preview.png` 中的第三版 Logo 已确认为正式 App Logo，并已用于高保真登录页；前两版不再是正式方案；
- 正式前端开发无需等待所有后续 UI 细节全部确认；
- 实现时可以根据浏览器实际效果进行必要适配，但不得擅自改变整体视觉方向；
- 原型中的示例鸟名、轮廓名称、颜色名称、具体文案和演示记录不因视觉基线获确认而成为正式业务数据；
- 原型中的每一项微交互不自动成为不可调整的最终规格；
- `prototype/experiments/visual-direction-comparison.html` 保留为 B′ 形成过程中的视觉实验记录，不再承担正式实现基线职责。
